# Динамический остров для Android

Капсула в стиле iPhone Dynamic Island над камерой Android — отдельным приложением, с настройками в оформлении как на скриншотах (тёмная тема, лавандовый акцент, карточки с переключателями, плавающая нижняя панель).

Идея и поведение перенесены с ПК-версии [mihailkotovski/DynamicIsland](https://github.com/mihailkotovski/DynamicIsland) (WPF / .NET 8) и переписаны под Android на Kotlin + Jetpack Compose.

## Что умеет

| Карточка | Свёрнутая капсула | По нажатию (раскрыта) |
| --- | --- | --- |
| **Музыка** | обложка слева от камеры, эквалайзер в цвет обложки справа (или строка песни) | обложка, название, 3 строки синхронного текста песни, перемотка, «назад / пауза / вперёд» |
| **Таймер** | песочные часы и обратный отсчёт, последние 10 с — красным | кольцо остатка вокруг кнопки паузы, отмена; по окончании — звонок и вибрация до нажатия |
| **Секундомер** | время | пауза, сброс, стоп |
| **Таймер / секундомер Google Часов и звонки** | значок приложения и время из уведомления | крупное время, нажатие открывает приложение |
| **Прогресс** (Google Play, Telegram, загрузки…) | значок приложения и кольцо прогресса | название, полоса и проценты |
| **Фонарик** | жёлтый значок | кнопка «Выключить» и яркость фонарика (Android 13+) |
| **Громкость** | полоска громкости, её можно тянуть пальцем | — |
| **Зарядка** | молния и процент | полоса заряда |
| **Пустой остров** | маленькая капсула над камерой | часы, дата, заряд, запуск таймера 1–99 мин, секундомер, фонарик |

Если активностей две (например, музыка и таймер), вторая уходит в круглый **пузырь** рядом с островом — как в ПК-версии. Нажатие на пузырь раскрывает её.

**События** (короткие уведомления в капсуле, каждое включается отдельно): зарядка началась/остановлена, низкий заряд 5%, Wi-Fi подключён/отключён, Bluetooth-наушники подключены/отключены (с зарядом, если система его сообщает), режим полёта, режим звонка (звук/вибрация/без звука), адаптивная яркость, USB-устройство, разблокировка.

### Жесты

| Действие | Результат |
| --- | --- |
| Нажатие | раскрыть (настраивается: открыть приложение, пауза, следующий трек, ничего) |
| Двойное / долгое нажатие | настраивается (по умолчанию долгое — открыть приложение) |
| Потянуть вниз | раскрыть — капсула тянется за пальцем |
| Потянуть вверх, нажатие или касание вне острова | свернуть |
| Толкнуть влево / вправо | следующий / предыдущий трек |
| Нажатие на звонящий таймер | выключить звонок |

### Настройки капсулы

Размер (ширина, высота) и положение (по горизонтали, отступ сверху) — капсула меняется на экране сразу. Цвет капсулы, контур (цвет, толщина, цвет из обложки), тень. Стиль раскрытия («Как Фрукт» — с эффектом желе, «Пружина», «Плавно», «Без анимации»), длительность и упругость анимации, «Уменьшить эффекты», виброотклик, скрывать пустую капсулу, скрывать в альбомной ориентации.

## Установка

1. Скачайте `DynamicIsland.apk` из артефактов последней сборки во вкладке **Actions** (или из **Releases**, если есть тег) и установите.
2. Откройте приложение → **Спец. возможности** → включите «Динамический остров».
   На Android 13+ переключатель может быть серым: «О приложении» → «⋮» → **Разрешить ограниченные настройки**, потом снова шаг 2.
3. Включите **Доступ к уведомлениям** — без него не будет музыки, прогресса и таймеров Google Часов.
4. На Android 12+ можно выдать **Bluetooth**, чтобы видеть имена наушников.
5. «Настройки Капсулы» → «Размер и положение» — подгоните капсулу под вырез камеры.

На Xiaomi/Huawei/Samsung разрешите автозапуск и снимите ограничения батареи, иначе прошивка может выгружать службу.

## Сборка

Нужны JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

Каждый push собирается GitHub Actions ([android.yml](.github/workflows/android.yml)), APK лежит в артефактах сборки. Тег `v*` дополнительно создаёт релиз.

Сборки подписываются ключом из `keystore/` — он нужен лишь для того, чтобы новые APK ставились поверх старых. Для публикации в магазине замените его своим.

## Как устроено

| Файл | За что отвечает |
| --- | --- |
| `service/IslandService.kt` | Служба спец. возможностей: окно `TYPE_ACCESSIBILITY_OVERLAY` поверх строки состояния, размер окна = размер капсулы, касание мимо сворачивает |
| `service/NotifListener.kt` | Доступ к уведомлениям: прогресс, секундомеры/таймеры из уведомлений, запуск `MediaMonitor` |
| `service/MediaMonitor.kt` | Системные медиасессии любого плеера, выбор играющей, обложка и цвет из неё (Palette), загрузка текста |
| `service/SystemEvents.kt` | Зарядка, Wi-Fi, наушники, режим полёта, звонок, яркость, USB, разблокировка, громкость |
| `service/TorchController.kt`, `TimerAlarm.kt` | Фонарик и его яркость; звонок таймера |
| `lyrics/LyricsRepo.kt` | Поиск и разбор синхронного текста с LRCLIB |
| `core/IslandBus.kt`, `Controls.kt`, `Models.kt` | Общее состояние острова, очередь событий и команды |
| `island/IslandOverlay.kt` | Выбор главной активности и пузыря, форма, пружины, «желе», жесты |
| `island/Compact.kt`, `Expanded.kt` | Свёрнутые и раскрытые виды всех карточек |
| `data/Settings.kt` | Все настройки (kotlinx.serialization в SharedPreferences) |
| `ui/` | Приложение настроек |

### Что изменено под Android по сравнению с ПК-версией

- Окно рисуется службой спец. возможностей — только она может рисовать над камерой и строкой состояния без отдельного разрешения «поверх других окон».
- Окно острова размером с саму капсулу (`WRAP_CONTENT`), поэтому касания рядом проходят в приложения, а не перехватываются.
- Компактный вид разделён на левую и правую части одинаковой ширины — вырез камеры всегда остаётся посередине; пузырь уравновешивается пустым местом слева.
- Анимации эквалайзера и тиканье часов работают только пока карточка видна; на паузе эквалайзер замирает. «Уменьшить эффекты» выключает их совсем.
- Музыка берётся из медиасессий Android вместо GSMTC, спектр WASAPI заменён эквалайзером (захват звука требует отдельного разрешения на запись).
- Запись OBS, полка файлов, QR-код с экрана и погода в ПК-версии завязаны на Windows и в эту версию не перенесены.
